# Changelog

## 0.1.0

- Ten layouts: Center Stage, Classic 2004, Clean Slate, Healer Focus, Mirror
  Panels, Controller, Ultrawide, Questing, Battleground, Laptop.
- Layout picker with a sketch of each layout and the settings it changes.
- Applies through Edit Mode as an account layout named DialedInUI.
- Undo restores your previous layout, settings and action bars.
- `/dialed check` builds every layout against the running client.
